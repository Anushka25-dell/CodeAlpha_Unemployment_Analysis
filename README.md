# Unemployment Analysis with Python

## Project Overview

This project analyzes unemployment trends in India using Python. It explores unemployment rates across different regions and areas and examines changes during the early COVID-19 period.

## Objectives

- Analyze unemployment trends over time.
- Compare unemployment rates across Indian regions.
- Study differences between Rural and Urban areas.
- Explore unemployment-rate changes during the early COVID-19 period.
- Visualize patterns using graphs and charts.

## Dataset

The project uses the **Unemployment in India** dataset, which contains information such as:

- Region
- Date
- Frequency
- Estimated Unemployment Rate (%)
- Estimated Employed
- Estimated Labour Participation Rate (%)
- Area

The analyzed data covers May 2019 to June 2020.

## Tools and Technologies

- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Analysis Performed

1. Data loading and inspection
2. Data cleaning and missing-value handling
3. Duplicate-record checking
4. Descriptive statistical analysis
5. Unemployment-rate distribution visualization
6. Unemployment trends over time
7. Region-wise unemployment comparison
8. Rural and Urban unemployment comparison
9. Comparison of unemployment before and during the early COVID-19 period

## Key Findings

- The average unemployment rate before April 2020 was approximately 9.61%.
- The average unemployment rate during April–June 2020 was approximately 20.19%.
- The average unemployment rate in Rural observations was approximately 10.32%, compared with 13.17% in Urban observations.
- The dataset shows differences in average unemployment rates across regions.
